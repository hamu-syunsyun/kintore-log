# 筋トレノート

自宅ダンベル（5kg固定）向けのトレーニング記録アプリ。
手書きノート風のシンプルなPWAで、サーバー不要・完全オフライン動作。

## 機能

- **A日／B日のメニュー表示** … 上半身／下半身の2分割。前回の記録から次に行う日を自動で提案
- **ワンタップ入力** … 枠をタップすると規定回数が入る。一括入力ボタンも用意
- **左右べつ記録** … 片手・片脚種目は左右を別々に記録
- **左右それぞれのタイマー** … 「左が次に使えるまで」「右が次に使えるまで」を同時にカウント。終了時に音とバイブレーションで通知
- **カレンダー** … 月表示でA日／B日の実施状況を確認。過去の日付に遡っての記録も可能
- **からだの記録** … 体重・筋肉量・スコアを折れ線グラフで表示
- **段階の記録** … 種目ごとに「回数→テンポ→片側→セット数」の進み具合を5段階で記録
- **書き出し／読み込み** … JSONでバックアップ

## 導入手順

GitHub Pages にそのまま置けます。

1. このリポジトリを自分のアカウントに作る
2. ファイル一式（`index.html` / `manifest.json` / `sw.js` / アイコン3つ）をコミット
3. Settings → Pages → Source を `main` ブランチのルートに設定
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

スマホでは、開いた後に

- iPhone … Safari の共有ボタン →「ホーム画面に追加」
- Android … Chrome のメニュー →「アプリをインストール」

でホーム画面に追加できます。以降はオフラインでも動作します。

## データについて

記録はブラウザの `localStorage` に保存されます。

- サーバーには何も送信されません
- 端末ごとに別のデータになります（端末間の同期は行われません）
- ブラウザのデータを消すと記録も消えます
- 「設定」タブから JSON で書き出し・読み込みができるので、機種変更のときはこれで移行してください

## メニューの編集

`index.html` の冒頭にある `PLAN` を編集してください。

```js
{n:"種目名", t:"表示ラベル", s:セット数, d:規定回数, r:セット間の休み秒, u:1, sw:左右切替の休み秒}
```

- `u:1` をつけると左右べつ入力になります（`sw` も一緒に指定）
- `u` がなければ通常の種目です

## ファイル構成

```
index.html          本体（HTML/CSS/JS すべて）
manifest.json       PWA設定
sw.js               Service Worker（オフライン用）
icon-192.png        アイコン
icon-512.png        アイコン
apple-touch-icon.png  iOS用アイコン
```

## 注意

内容は一般的なトレーニング・栄養の目安です。痛みや体調不良がある場合は中止してください。
